# 엔드필드 오퍼레이터 육성 플래너

[플래너 열기](https://seoltaang.github.io/arknight-agent-planner/)

오퍼레이터의 현재 육성과 성장 목표를 기록하고, 필요한 재료와 파밍 계획을 확인하는 웹 앱입니다.

## 사용하기

- **성장 목표**: 카드에서 준종결·종결을 선택하거나, ‘직접 설정’으로 상세 패널을 엽니다.
- **현재 상태 적용**: 준종결은 Lv.80 / 정예 4 / 스킬 9, 종결은 Lv.90 / 정예 4 / 스킬 12로 입력합니다. 두 경우 모두 전체 노드를 해금하고 보유 상태로 바꿉니다. 성장 목표·플랜·보유 재료·메모·사용자 이미지는 유지합니다.
- **되돌리기**: 적용 직후 알림 또는 상세 패널에서 이전 현재 상태로 복구할 수 있습니다. 이후 육성 수치를 수동 수정하거나 데이터를 가져오면 오래된 되돌리기는 적용되지 않습니다. 새로고침하면 되돌리기 기록은 사라집니다.
- **진행률**: 레벨·정예화·스킬·노드의 목표 달성 비율을 균등 평균합니다. 목표에 필요 없는 항목은 제외합니다. 재료 확보량이나 육성 시간의 비율은 아닙니다. 모든 목표를 달성해야 100%이며, 미보유는 ‘—’로 표시합니다.
- **검색·필터**: 한글·영문 이름 검색, 보유만·플랜만 모아보기와 상세 필터를 제공합니다.

기록은 브라우저에 자동 저장되므로 다른 기기로 옮길 때는 ‘내보내기 / 가져오기’를 사용하세요.
