# 엔드필드 오퍼레이터 육성 플래너

[플래너 열기](https://seoltaang.github.io/arknight-agent-planner/)

오퍼레이터의 현재 육성과 성장 목표를 기록하고, 필요한 재료와 파밍 계획을 확인하는 정적 웹 앱입니다. 캐릭터 33명과 기본 이미지 62개를 포함합니다.

## 사용하기

- **성장 목표**: 카드에서 준종결·종결을 선택하거나, ‘직접 설정’으로 상세 패널을 엽니다.
- **현재 상태 적용**: 준종결은 Lv.80 / 정예 4 / 스킬 9, 종결은 Lv.90 / 정예 4 / 스킬 12로 입력합니다. 두 경우 모두 전체 노드를 해금하고 보유 상태로 바꿉니다. 성장 목표·플랜·보유 재료·메모·사용자 이미지는 유지합니다.
- **되돌리기**: 적용 직후 알림 또는 상세 패널에서 이전 현재 상태로 복구할 수 있습니다. 이후 육성 수치를 수동 수정하거나 데이터를 가져오면 오래된 되돌리기는 적용되지 않습니다. 새로고침하면 되돌리기 기록은 사라집니다.
- **진행률**: 레벨·정예화·스킬·노드의 목표 달성 비율을 균등 평균합니다. 목표에 필요 없는 항목은 제외합니다. 재료 확보량이나 육성 시간의 비율은 아닙니다. 모든 목표를 달성해야 100%이며, 미보유는 ‘—’로 표시합니다.
- **검색·필터**: 한글·영문 이름 검색, 보유만·플랜만 모아보기와 상세 필터를 제공합니다.
- **라이트·다크 모드**: 처음에는 시스템 설정을 따르며, 상단 버튼으로 선택한 모드를 이 브라우저에 저장합니다.

관리자는 남녀 공용 초상화를 사용하고 육성 기록도 공용입니다. 기록은 브라우저에 자동 저장되므로 다른 기기로 옮길 때는 ‘내보내기 / 가져오기’를 사용하세요.

## 실행과 검증

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

두 HTML 파일은 동일합니다. 배포할 때 `assets/` 폴더를 함께 포함해야 합니다. 기본 캐릭터·재료 이미지는 외부 CDN 연결 없이 표시됩니다.

Python 3, Node.js, Playwright와 Chromium이 설치된 환경:

```sh
node tests/planner.cjs
```

Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 테스트는 자체 서버와 별도 브라우저 데이터를 사용합니다.

캐릭터·비용·이미지의 출처와 신규 보스 보상량의 확인 범위는 [DATA_SOURCES.md](DATA_SOURCES.md)에 기록했습니다.
